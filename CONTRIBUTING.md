# Contributing to this Project

We welcome contributions from the community! Whether you are fixing a bug, adding a feature, or improving documentation, your help is appreciated.

## How to Contribute

1. **Fork the Repository**: Create a personal copy of this repository on GitHub.
2. **Clone Locally**: Clone your fork to your development machine.
3. **Create a Branch**: Create a new branch with a descriptive name:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make Changes**: Write clean, commented code and ensure tests pass.
5. **Commit Changes**: Use clear commit messages following conventional commits:
   ```bash
   git commit -m "feat: add support for active subdomain checking"
   ```
6. **Push and Submit PR**: Push your branch to GitHub and open a Pull Request against the `main` branch of the parent repository.

## Development Guidelines

- Keep code modular and preserve existing comments.
- Update the `README.md` if your changes introduce new configurations, CLI flags, or dependencies.
- Follow PEP 8 guidelines for Python code.
