# Security Policy: Vanguard Vulnerability Scanner

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ Yes    |

## Reporting a Vulnerability

Vanguard is designed to run automated security audits on targets. If you discover a bug that leaks scanner states or crashes the prober during parsing, please report it responsibly:
1. Email your findings to the repository maintainers.
2. Provide a sample target endpoint layout that triggers the crash or exception.
3. We will patch the issue in the next minor version release.
